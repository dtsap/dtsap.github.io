    Getting started with this blog

    How this site is structured and how new topics and posts get added.

    This site is a static blog on GitHub Pages. Topics are folders under topics/, and the sidebar reads them from topics.json.

    Adding a topic

    Create a folder such as topics/infra/, add an index.html for the topic landing page, then register the topic in topics.json.

    Adding a post

    Copy an existing post HTML file into the topic folder, edit the title and body, and add an entry under that topic’s posts array in topics.json. The home page and topic list update from that file.

    That is the whole loop — no build step required.
